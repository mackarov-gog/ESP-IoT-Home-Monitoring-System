# ESP IoT Home Monitoring System

## 🏠 Что это за программа?

Это прошивки для микроконтроллеров семейства ESP, которые превращают модуль в полноценный узел умного дома. Проект поддерживает веб-интерфейс для настройки микроконтроллера, передачу данных по протоколу MQTT и локальный мониторинг.

Вот финальный текст для твоего **README.md**. Я добавил информацию о разделении платформ и о том, что файл теперь является общим руководством для всей линейки устройств.

## 📋 Поддерживаемые платформы

На данный момент проект разделен на ветки/файлы в зависимости от используемого железа:

* **ESP8266**: Стабильная версия (основной код в папке проекта). Оптимизирована для базового мониторинга.
* **ESP32**: В данный момент ведутся активные работы по портированию (находится в разработке).

## 🛠 Важное примечание по датчикам

В текущем состоянии проект находится в **режиме демонстрации**:

* В файле `sensors.cpp` (для ESP8266) используются **псевдо-датчики** (генерация случайных чисел).
* Это позволяет проверить работу веб-интерфейса и MQTT без наличия физических компонентов.

### Как перейти на реальные датчики:

Архитектура проекта построена по принципу **"Одного файла"**. Вам **не нужно** менять логику в `main.cpp`, `WebServer.cpp` или `ConfigManager.cpp`. Все изменения вносятся только в папку **Sensors**:

1. **`sensors.h`**: Добавьте нужные поля в структуру `SensorData`.
2. **`sensors.cpp`**:
* В методе `begin()` инициализируйте реальное железо (например, `dht.begin()`).
* В методе `update()` замените `random()` на чтение с пинов.
* В методе `publishToMqtt()` пропишите отправку данных в ваши топики.
* В методе `appendToJson()` добавьте данные для отображения в веб-интерфейсе.


## 🚀 Основные возможности

* **Конфигурация без прошивки**: Если настройки WiFi не найдены, устройство создает точку доступа `IoT-Config-XXXX`. Все параметры (WiFi, MQTT) вводятся через браузер.
* **Централизованное управление**: Логика формирования данных для MQTT и Web-API полностью изолирована внутри `SensorManager`.
* **Живой мониторинг**: Главная страница устройства автоматически обновляет показания в реальном времени.
* **JSON API**: Легкая интеграция с внешними системами через эндпоинт `/api/status`.
